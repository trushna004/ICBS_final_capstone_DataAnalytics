Capstone package

Included files:
- capstone_healthcare_readmission_analysis.ipynb.
- README.txt
- diabetic_data.csv
- cms_readmissions.csv
- IDS_mapping.csv

Instructions:
1. Clone the repo at suitable location.
2. Open the notebook and run cells top-to-bottom in Jupyter. The notebook will generate IDS_mapping.csv if not present by sampling facility IDs from cms_readmissions.csv.
3. Export the notebook to HTML via File -> Download as -> HTML.
Note: The generated IDS_mapping.csv is synthetic (random mapping) and for demonstration only. Use real mappings or a DUA dataset for production analysis.
